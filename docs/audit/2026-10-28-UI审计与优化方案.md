**P2 视觉问题（截图实证）**
- 深色扁平化：`--as-bg #0d110e` vs `--as-bg-elev #141a15` 明度差 <6%，黑底上黑阴影（`0 8px 30px rgba(0,0,0,.35)`）无效 → 卡片"浮不起来"（3 批视觉分析一致指出）

- 金色权重不均：主按钮/标签/数字/导航多处抢焦点
- 浅色 `--as-text-faint #6e6960` on `#e7e1d1` ≈ 4.2:1 < WCAG AA 4.5:1，用于 10.5~11px 微字（系统性）
- 红底白字角标 ≈ 3.4:1（:99,:270,:912，10~12px 小字）
- 弹窗特殊控件无设计语言：卡片式选项（目录构建模式/绑定方式）、按钮组（预设模板）、标签列表各自为政

- 按钮无 `:active` 按压态；无 `prefers-reduced-motion` 降级（skeleton/typing/pulse 无限动画）
- `window.confirm` ×16 与弹窗体系分裂
- 空状态图标 AppIcon 与 12 个 emoji 混用（emoji 无 aria-hidden）

**P3 可访问性**
- 答题选项 `.option` 是 div 无 tabindex/role（QuizView.vue:28-57）——**键盘用户无法完成核心作答流程**
- 可点击 div 无键盘可达：`.mode-card`/`.course-select`/`.tree-node .row`/`.kp-item.clickable`/`.log-row`/`.switch`×2

## 二、P0 功能 bug 修复

### 2.1 `.analysis` 解析不显示
- 现状：:819 `.analysis { margin-top:10px; padding:10px 14px; font-size:12.5px; color:var(--as-text-dim); background:var(--as-bg-elev2); border-radius:var(--as-radius-sm); }` 与 :914-917 `.analysis { display:none; ... } / .analysis.show { display:block } / .analysis .lbl / .analysis p` 冲突，后者生效；模板 `QuizView.vue:86` `v-if="quizResult && currentQuestion!.analysis"` 不带 `.show`。
- 改法：**删除 style.css:914-917 四条规则**（`display:none` 版 + `.show` + `.lbl` + `.p`），保留 :819 版。`v-if` 已控制显隐，无需 JS 改动。
- 验证：英语课程题库找一道有解析的题（或临时给一题写解析）→ 答题提交 → 判分行下方出现解析块。

### 2.2 `.dist-bar` 报告堆叠条被压扁
- 现状：ReportView.vue:57 用 `.dist-bar > .dist-seg`（:872 高 26px 设计）；CourseHomeView.vue:64 用 `.dist-row > .dist-bar > .dist-fill`（:1158 高 8px 设计）。后者覆盖前者 → 报告页堆叠条变 8px，分段内 ≥12% 的数字（ReportView.vue:59）被裁。
- 改法：`:1158` 的 `.dist-bar { flex:1; height:8px; ... }` 重命名为 **`.dist-track`**，同步改 `CourseHomeView.vue:64` 的 `class="dist-bar"` → `class="dist-track"`。`.dist-fill` 规则不变（挂在 `.dist-track` 下，选择器同步改）。
- 验证：报告页"掌握度分布"恢复 26px 堆叠条且分段数字可见；课程主页分布行仍为 8px 细条。

### 2.3 `--as-yellow` / `--as-teal` 未定义
- 改法：在两个主题变量块补定义（`.tag.cloze`/`.tag.translation` 仅用 `color` + `border-color: currentColor`，只需主色）：
  - 暗色：`--as-yellow: #d6c062; --as-teal: #62b8ac;`
  - 浅色：`--as-yellow: #7d6a14; --as-teal: #2e7a6d;`（浅色系加深保对比度，风格对齐现有语义色取值逻辑）
- 验证：刷题页/错题本筛选 chip 与题目 tag，填空/翻译类型显示黄/青色。

### 2.4 `.fc-*` 闪卡列表无样式
- 结构（FlashcardsView.vue:60-68）：`.fc-list > .fc-item > .fc-front + .fc-foot(src-tag/kp-tag/日期/按钮×3)`
- 改法：参照 `.q-fixed`（:783）模式补定义：
  ```css
  .fc-list { display: flex; flex-direction: column; gap: 8px; }
  .fc-item { padding: 10px 14px; background: var(--as-bg-elev2); border: 1px solid var(--as-border-soft); border-radius: var(--as-radius-sm); }
  .fc-front { font-size: 13px; line-height: 1.6; margin-bottom: 8px; }
  .fc-foot { display: flex; align-items: center; gap: 8px; font-size: 11.5px; }
  ```
- 验证：闪卡本列表卡片化、有间距与边框。
