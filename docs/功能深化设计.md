 ### F-A3 知识点树导出 / 导入（roadmap A4，T3.8②，含可编辑往返）

 **交互**
 - 课程内容页「导出知识点树」：选项勾选 含掌握度（默认✓）/ 含错题数 / 仅未掌握；文件名 `{课程名}-知识点树-YYYYMMDD.md`
 - 课程内容页「导入知识点树」（归档课程不显示）：选文件 → 解析校验 → 变更预览（更新/新增/删除知识点 + 章节变更，删除逐条列名）→ 确认后落盘；零变更时按钮置灰「无变更」

 **往返格式（导出即可导入的往返文件）**
 - 说明头（HTML 注释块）：`课程：X（course:ID）` 身份锚点 + 8 条使用说明；`onlyUnmastered` 过滤版在头部声明**不可用于导入**（防已掌握知识点被误删），导入器拒收
 - 章/小节行带 `<!-- ch:ID -->`、知识点条目带 `<!-- kp:ID -->` 身份标记（改名安全的匹配锚点）
 - 知识点内容缩进 2 空格导出，空行分段，多段落可往返
 - 孤儿/幽灵归属的知识点归末尾「未归章」（虚拟分组，无标记）
 - 说明头可删：删除后按一级标题「课程名 知识点树」兜底校验课程；两者皆无则允许但 UI 警示

 **导入规则（文件即真相）**
 - 按 ID 匹配：更新 name/content/章节归属/顺序；文件中标记缺失的现有知识点=删除（预览确认）；无标记条目/章节=新建（知识点默认「未学习」）
 - **绝不动**：mastery、题目/闪卡/复习排期/学习日志、思源文档绑定 blockId、tags；章节改名时子树内知识点 chapterName 同步刷新
 - 课程校验：优先 `course:ID` 严格相等；无 ID 时按标题课程名模糊匹配，不符则拒收

 **实现**：`utils/kpTreeExport.ts`（buildKpTreeMarkdown）+ `utils/kpTreeImport.ts`（parse/diff/apply 纯函数）+ `api/kpTreeImport.ts`（preview/confirm）+ `components/KpTreeImportModal.vue`；测试 `kpTreeExport.test.ts`（7）+ `kpTreeImport.test.ts`（23，含往返零变更）

 **验收（真机已过）**：导出→编辑（改名/多段落/删/跨章移动/新章/新条目）→导入预览 7 处变更→确认→再导出与编辑文件逐条一致、12 个既有知识点掌握度全保持；原样文件再导入显示「无变更」

## 阶段 B（备考核心，设计最重）

### F-B1 真题链路（roadmap B1）

#### F-B1a 试卷导入增强

**现状**：`QuestionImportModal`（Markdown 解析已含 CRLF/多选项/`- A. ` 前缀等测试覆盖）+ `ExamPaper` 实体 + `Question.paperId` 挂接

**增强**：导入弹窗加「作为试卷导入」——填试卷名/年份 → 自动建 `ExamPaper` + 绑定全部导入题的 `paperId`；导入报告保留（N 解析 / M 失败 + 原因）

**验收**：导入 20 题真题 → 试卷列表出现、题目 `paperId` 正确、按试卷组卷可用

#### F-B1b AI 反挂知识点（新 AI 任务 `map_question_kps`）

**交互**：题库筛选「未绑定知识点」或试卷详情 → 「AI 绑定知识点」→ 后台任务（复用 bgTask：可取消 / 失败重试 / 完成进通知中心）→ **结果确认弹窗**（核心交互）：

| 题干摘要（截 40 字） | AI 建议（chip 可删） | 手动补选（KpTreePicker） | 操作 |
|---|---|---|---|
| 「2024 第 3 题 关于…」 | [存货计价] [成本计算] | ＋ | 应用 / 跳过 |

- 底部批量：「全部应用（默认）/ 仅应用建议 ≥1 / 按逐条勾选」

**规则**
- 输入：题干+选项（截断）+ 答案 + KP 清单（名+描述）；批量 20 题/批
- KP 清单沿用 100 条 / 60k 字符硬上限（R4.6 口径），超限提示「先缩小到具体章节」
- 输出 `{qId, kpIds: string[]}`，`parseAiJson` 防御解析；非法 qId 丢弃并计数
- 批失败不中断整体（现有 extract 模式），失败批次可重跑；单题 0 建议 = 正常（保留「跳过」）
- 写入 = **追加合并** `Question.kpIds`（去重并集，与批量绑定语义一致），不覆盖人工已绑

**数据变更**：无新实体（写 `kpIds`）

**验收**：20 题未绑真题 → 反挂 → 确认表 3 题删建议 / 2 题补选 / 1 题跳过 → 应用后 `kpIds` 正确、按 KP 组卷命中、通知中心有结果通知

#### F-B1c 缺口补题（复用 `gen_question`）

**交互**：试卷详情/题库统计卡「知识点覆盖表」：每 KP 行 = 名称 | 绑定题数 | 条形；题数 < 目标（默认 2，可配 0–5）标「缺口」；勾选缺口 KP → 「AI 补题」→ 现有出题管线（数量 = 目标 − 现有，逐 KP）

**规则**
- 新题 `source=ai` + `kpIds` 绑定 + `paperId=null`（进题库不进原卷）
- 复用限流 / 重试 / 取消机制

**数据变更**：无新实体

**验收**：5 个 0 题 KP → 补题 → 10 新题入库、覆盖表刷新、可按 KP 组卷

### F-B2 考试倒计时 + 冲刺模式（roadmap B2）

#### F-B2a 考试日期

**数据变更**：`Course + examDate?: string`（YYYY-MM-DD；旧数据无 = 不显示）

**交互**：新建课程弹窗 + 课程主页可设/改；课程顶栏/主页 countdown chip「距考试 12 天」（≤7 天变色警示）

#### F-B2b 冲刺模式（纯函数排期引擎，可单测）

**触发**：自动（`examDate − today ≤ sprintDays`，默认 14，可配 7/14/21）或计划页手动开关

**规则**（作用于该课程 active 计划；激活时一次性重排 + 展示 diff 摘要「N 项 learn 提前 / M 项复习间隔压缩」）
1. 未完成 learn 任务 → 重排至剩余天数的**前半段**（T−7 前必须学完，留纯复习窗口）
2. 复习间隔压缩：`ReviewSchedule.intervalDays × 0.5`（下限 1 天），未到期项重算 `dueTime`
3. 薄弱优先：挂 `weakKps` 知识点的任务排期前移（sort 调整）
4. 每日任务上限：冲刺期放宽（现有顺延机制不动）

**退出**：不自动回滚（保持冲刺后排期；用户可沿用「延期」语义手动调）——回滚语义歧义大，明确不提供

**数据变更**：`StudyPlan + sprintMode?: boolean`；任务/排期只改 `scheduledDate`/`sort`/`dueTime` 值，结构不变

**边界**
- 无 active 计划 → 只显 countdown，横幅提示「先生成计划」
- 计划已暂停 → 冲刺不生效（提示先恢复）
- `examDate` 已过 → 横幅转「考试已结束」归档态

**验收**：纯函数测试矩阵（重排/压缩/薄弱优先/无计划/已暂停/边界日期）+ 真机冒烟：设考试日 → 自动进冲刺 → diff 摘要正确 → 恢复后数据一致

#### F-B2c 备考建课模板（轻量）

新建课程「目录构建模式」加「考试备考」预设：auto 目录 + 引导语（第一资料建议传考纲）+ 目标日期=考试日期联动；无新实体

## 阶段 C（多端同步）

### F-C0 数据模型地基（roadmap B3 前置，随 server 包落地）

- **全部实体加 `updatedAt: string`**：写入口统一置位（`commitData` 脏集机制已能报出变更集合，细化到实体粒度即可）；读取端旧数据缺失 = 回退 `createTime`
- **墓碑**：删除不再物理抹除视图 → 服务器端 tombstone 表（`entityType + entityId + deletedAt`）；客户端 AppData 不变（仍物理删），同步层负责
- **关键设计点**：**设备级连接配置不进同步数据**（服务器地址/token 存各端本地：思源 petal 独立文件或 localStorage；避免「连接配置被同步覆盖」死循环）

### F-C1 思源在线模式（roadmap C1/C2）

#### F-C1a 连接配置

- 设置页新增「数据服务器」节：服务器地址（`http://NAS:port/app/ai-study`）+ 访问 token（fnOS 应用「设备与接入」页生成，见 F-C1d）+ 「测试连接」（healthz + 鉴权）
- 模式开关：本地模式（默认，现行为不变）/ 在线模式

#### F-C1b 同步协议

- **Push**：客户端实体级脏集 → `POST /sync/push { changes: [{entityType, id, data | tombstone, updatedAt}] }`
- **Pull**：`GET /sync/pull?since=<cursor>`（cursor = 客户端见过的最大 `updatedAt`，存设备本地）→ 返回变更实体 + 墓碑
- **冲突**：实体级 LWW（按 `updatedAt` 比较）；push 优先、pull 补合；同一实体两端都改 → 同步后冲突报告「1 项以本机为准覆盖了其他端改动」
- **调度**：启动即同步 + 保存后防抖 2s 自动 + 手动「立即同步」；顶栏状态指示（🟢已同步 / 🟡同步中 / 🟡离线排队 / 🔴连接失败）
- **离线降级**（L3-lite）：断网时读写 petal 本地缓存，push 进队列（脏集天然就是队列），重连自动补发；**不做** CRDT / 离线合并算法，LWW 兜底

#### F-C1c 存量迁移（一次性向导，roadmap C2）

- 首次切在线模式 → 「迁移本地数据到服务器」：全量 push（不带 since）+ 报告（N 课程 M 题 K 闪卡…）
- 服务器已有同名课程 → 三选一：跳过（默认）/ 合并（按实体 LWW）/ 覆盖；迁移后 petal 保留为缓存不清空

#### F-C1d fnOS 设备管理

- fnOS 应用设置页「设备与接入」：token 列表（名称 / 最后活跃 / 生成 / 删除）；每 token = 一个客户端身份（多租户地基复用）

**验收（F-C1 整体）**
- SiYuan 在线模式连接 → 其学习数据在 fnOS UI 可见（2s 防抖）；反向同理
- 断网 5 分钟继续学 → 重连 → 队列补发无丢失
- 冲突报告出现且口径正确
- 删除 token → SiYuan 提示重配

### F-C2 PWA 客户端硬化（roadmap C3）

- **离线只读壳**：SW 缓存最近一次数据快照（按课程 JSON，数据变更时更新）→ 离线可浏览/查看，写操作全禁 + 横幅提示
  - 注意：PWA **无本地库，离线变更不排队**（排队属于思源在线模式的 petal 缓存语义）——写禁而非假排队，诚实告知
- **本地通知**：Notification API（用户授权）：每日首次打开 + 09:00（页面在场时）「今日 M 项复习到期」；不做 SW 后台推送（移动端兼容性差）

**验收**：清缓存重装仍秒开；离线浏览缓存课程正常、写禁用；通知权限流正确

### F-C3 S3/WebDAV 备份（roadmap C5）

**配置**（设置页「数据备份」节）
- S3：endpoint / AK / SK（复用 `crypto.ts` 加密存储）/ bucket / prefix
- WebDAV：url / 用户名 / 密码 / 路径
- 测试连接按钮

**规则**
- 内容：全局配置 + 逐课程 zip（复用 `coursePackage` 导出），文件名 `{courseId}-{课程名}-YYYYMMDD-HHmm.zip`
- 触发：手动 + 每日 03:00 自动（应用在运行时）
- 保留：远端保留最近 N 份（默认 7，可配 0–30），旧的 best-effort 删除（失败仅记日志）
- 恢复：「从备份导入」→ 选端点文件 → 现有课程包导入机制
- 可选：备份加密（密码 KDF → AES-GCM，默认关——端点本来就是用户自己的）

**验收**：手动/定时备份落远端；保留数滚动；恢复往返一致（课程数据 diff 为空）

### F-C4 自托管 Docker（roadmap C4）

- 镜像：node:22-alpine，server dist + UI dist，单端口；volume `/data`（SQLite + 资产）；env：`PORT` / `DATA_DIR`
- compose 模板一键；release 时 push ghcr

**验收**：非 fnOS 机器（Mac/任意 Linux）docker run → 浏览器全功能 + 可作 SiYuan 在线模式同步服务器

## 阶段 D（官方云，框架级——启动时单独出 spec 再深化）

- **账号**：邮箱+密码 → JWT；14 天免费试用 → 订阅（档位：设备数默认 3 / 存储默认 1GB，启动时定）
- **支付**：支付宝 + 微信支付先行（单人开发者现实选择）
- **加密**：E2EE-lite——payload 客户端加密；密钥 = KDF(密码) 经**服务器 key-wrapping**（允许换设备登录；纯本地密钥做不到）；云只存密文 + 包裹密钥
- **多租户**：F-C0 身份体系已按用户隔离，云模式加租户索引 + 配额中间件
- **明确暂不设计**：计费 UI 细节、SLA、合规、客服——启动阶段 D 时单独出 spec
