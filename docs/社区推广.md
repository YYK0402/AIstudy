# 我给思源做了个 AI 自学插件：丢进课程资料，AI 带着你学完——知识点、刷题、错题、间隔复习一套闭环

各位好，想介绍一个我自己开发的思源插件——**AI 智能学习**。

一句话概括：把你的课程资料（PDF / Word / PPT / 扫描件）丢进去，它帮你走完整条自学闭环：

**资料导入 → 知识点拆解 → 学习计划 → 讲解学习 → 题库刷题 → 错题复盘 → 间隔复习 → 学习报告**

几个我觉得值得说的点：

1. **自带 API Key，不绑任何厂商**：兼容任意 OpenAI 格式接口（MiniMax / DeepSeek / Kimi / 通义 / 自部署 Ollama 都行），每个 AI 任务还能单独指定模型、单独调提示词模板，不满意 AI 表现先改提示词。
2. **数据全在本机**：学习数据存思源本地，不经过第三方服务器；可选开启「落库」，课程 / 章节 / 资料 / 学习对话会以笔记文档形式存进你的笔记本，在思源里照常检索阅读。
3. **是学习闭环，不只是聊天**：
   - AI 从资料抽知识点、自动识别目录（可 AI 矫正）
   - AI 生成每日学习计划，最新版加了**甘特图视图**（章节 / 知识点排程条，周 / 月 / 季 / 年粒度聚焦）
   - 费曼式讲解：AI 提问 → 你用自己的话讲 → AI 评分，多轮补强
   - AI 出题（单选 / 多选 / 判断 / 简答 / 填空 / 翻译），即时批改、简答 AI 阅卷，也能导入真题组卷
   - 错题本（标记错误原因、连对毕业）+ 闪卡 + SM2 间隔重复到期浮现
   - 知识图谱（AI 推理前置关系 + 手动连线，掌握度着色）
   - 学习报告：薄弱点清单 TOP N，可导出 Markdown
4. **适用版本**：思源 3.8.0+；扫描版 PDF 的 OCR 仅桌面版可用。
