# 示例课设计（开箱即用）

> 状态：设计已定稿，待用户评审后进入实施计划。
> 最后更新：2026-10-30

## 1. 背景与目标

插件功能已很全，但新用户装完面对的是「空态」：要先配 API key、建课、传资料，才能体会到任何价值——这是集市插件最大的激活门槛。

目标：提供一门**开箱即用的示例课**，让新用户**点一下就能开始学**——无需上传资料、无需先配 AI。本文是方向 A（开箱即用 / 首启引导）的设计。

## 2. 设计决策（已与用户确认）

| 决策点 | 结论 |
|---|---|
| 内容来源 | **静态内置**（随包提交，不做运行时 AI 生成） |
| 入口形式 | **纯可选、不自动导入**——首页一张「试一试示例课」卡片 |
| 规模 / 科目 | **1 门 · 中规模**，科目 = 中国近代史（复用现有 mock 骨架扩成真实内容） |
| 知识产权 | **不含任何原始资料**（`materials: []`、无资产文件）；全部文本原创编撰 |
| 学习计划 | **保留**现成学习计划 + 任务 |

## 3. 数据范围与 IP 安全

- 示例课 = 课程 + 章节 + 知识点 + 题目 + 闪卡 + 现成学习计划 + 任务
- **不含资料**：`materials: []`、`materialChapters: []`、知识点 `sourceAssetIds: ""`
- 所有文本（知识点内容、题干/答案/解析、闪卡正反面）均为**原创编撰的事实性内容**——历史事实不受版权保护、措辞为原创，不抄任何教材原文 → 无 IP 风险
- 示例课的「资料」页为空；「打开原文」等依赖资料的入口走**无资料优雅态**（实施时验证不报错）

## 4. 数据模块

新增 `web/src/constants/sampleCourse.ts`：

- 导出 `SAMPLE_COURSE: CoursePackageData`（`materials: []`、`materialChapters: []`，内部本地占位 id）
  - `course`：`{ name: "示例课：中国近代史", description, target, totalCycle, status: "active" }`
  - `chapters`：4（平铺 `chapter` 级章节，无 `unit` 嵌套；`generateStudyPlan` 章末测评只认 `chapter` 级节点，功能等价）
  - `knowledgePoints`：~12（原创事实性内容，挂到对应章节）
  - `questions`：~20（单选 / 多选 / 判断 / 填空混合，`kpIds` 绑定知识点）
  - `examPapers`：1（可选，承载部分题目）
  - `flashCards`：~10（每知识点 1 张，`source: "manual"`）
- 内容为原创编撰（实施阶段的主要工作量，需保证事实准确 + 措辞原创）

## 5. `createSampleCourse()`

新增 `web/src/api/sampleCourse.ts`：

```
1. 防重：data.courses.some(c => c.isSample) 为真 → 直接返回/抛错（不重复添加）
2. existing = getData()
3. remapped = remapCoursePackage(SAMPLE_COURSE, existing)
   // 复用 coursePackage.ts：分配新 id + 重写全部外键 + 同名规避
4. remapped.course.isSample = true
5. saveData(applyImportToData(existing, remapped))
6. await generateStudyPlan(remapped.courseId, {
     startDate: formatLocalDate(new Date()),   // 今天
     targetDate: addDays(today, 14),           // 今天 + 14
     dailyHour: "1",
   })
   // 复用现有计划生成；无 gen_plan 绑定时自动降级为确定性骨架
7. return { courseId, courseName, counts }
```

- **复用**：`remapCoursePackage` + `applyImportToData`（coursePackage.ts）+ `generateStudyPlan`（plan.ts:339）
- **计划生成行为**：新用户通常无 `gen_plan` 模型绑定 → `generateStudyPlan` 走**确定性骨架**（`distributeKpsByDay` 按天均分知识点 → 每知识点一条 learn 任务 + 章末测评 + 结业模考），**无需 AI / 无需 key、即时、零成本**。若用户已配置 `gen_plan` 绑定，则会额外穿插 AI 补充任务（行为与正常生成计划一致，可接受）
- 两次 `saveData`（内容落盘 + 计划落盘），`generateStudyPlan` 内部会重新 `getData()`，因步骤 5 已保存，能读到示例课的知识点——安全
- 日期相对「添加当天」生成 → 「今日任务 / 甘特」立即可见

## 6. `isSample` 字段

- `Course` 类型（`src/data.ts`）新增 `isSample?: boolean`
- 用途：
  - 「试一试示例课」卡片显隐（无 `isSample` 课程时显示，有则隐藏）
  - 课程卡片打「示例」徽标
  - `createSampleCourse` 防重
  - 用户删除示例课后，因不再有 `isSample` 课程 → 卡片重现（可再加）

## 7. UI：「试一试示例课」卡片（HomeView）

- 「我的课程」网格内、与「＋新建课程」卡片**并列**
- **仅当无 `isSample` 课程时显示**
- 文案：标题「试一试示例课」+ 价值副文案「无需上传资料、无需先配 AI，点一下就能开始学」+ 描述「中国近代史 · 4 章 12 知识点 · 含现成题目与两周计划」
- 点击 → `createSampleCourse()` → toast「已添加示例课」→ 课程出现、卡片消失
- **无自动导入、无横幅、无 onboarding 标记**

## 8. AI 能力与 key 解耦

- **无 key 可用**：浏览章节 / 知识点、读知识点内容、答预置题（客观题自动批改）、翻预置闪卡、看现成计划 / 今日任务 / 甘特
- **需 key**：AI 费曼讲解、AI 出题、AI 抽知识点等
- 实现：现有 AI 功能已有「无绑定」处理（如 `generateStudyPlan` 降级骨架）；讲解 / 出题入口在**未配置服务商**时需给出明确引导「先配置 AI 服务商」+ 跳转设置（实施时核实现有行为，缺失则补引导）
