- 版本：v1.2（2026-10-21 按《完整课程学习全流程梳理》四阶段修订：计划确定性骨架、复习合轨、章节复盘/结业模考、增量重排）
- 范围：思源笔记插件 siyuan-ai-study
- 状态标记：✅ 已实现 ｜ 🟡 部分实现 ｜ ❌ 未实现
- 说明：「现状」均基于当前代码核实（文件/行为可查证）；「差距」列出一期需补齐的具体项与验收标准

## 完整学习流程总览（四阶段）

1. **准备阶段**：创建课程（含选模型）→ 导入资料（3 方式、可多次追加）→ AI 解析知识点树（增量）→ 人工校对 → 生成学习计划
2. **日常主循环**：今日队列（新知识点 + 到期复习 + 到期错题）→ 阅读 → 费曼复述 → AI 评估 → 自测刷题 → 错题入库 → 掌握度更新 → 间隔复习自动排程
3. **阶段复盘**：章节复盘（掌握度概览 + 章节组卷 + 错题导出）→ 薄弱点巩固 → 必要时调整计划（延期/增量重排）
4. **结业巩固**：全课程模考 → 薄弱点清单 + 学习报告 → 长期间隔复习 → 课程归档
- 分支：中途追加资料（增量解析 + 计划增量重排）、自由组卷刷题、模型切换

## 四、学习计划模块（冯·诺依曼学习理论闭环）

闭环目标：学习知识点 → 费曼输出复述 → AI 评估 → 自测刷题 → 识别薄弱点 → 追加复习任务。
现状（2026-10-22）：**掌握度自动更新、复述→自测引导、薄弱点追加任务、计划-学习挂钩、今日任务合轨、计划管理增强已落地**（T1.1-T1.6，批次一功能项全部完成）；剩余为服务商调用控制（T1.7-T1.11）与数据看板（T1.12）。
设计决策：阅读与复述**合成一条 learn 任务**（完成标准=复述≥60，阅读无机器可判完成信号）；计划生成采用**系统确定性骨架 + AI 穿插**（见 4.1）。
