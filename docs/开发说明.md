# AI 智能学习（monorepo：思源 / 飞牛双端）

可自定义大模型服务商的课程自学系统，融合费曼输出式学习法与间隔重复理论。支持资料导入、知识点拆解、学习计划生成、题库刷题、错题复盘、知识图谱、学习报告。同一套前端与业务核心，两个宿主适配端：

- **思源笔记插件**：入口在思源顶栏，点击后在思源窗口内以自定义页签打开
- **飞牛 fnOS 应用**（native .fpk）：桌面图标打开，内嵌 nitro 统一网关服务，支持从 NAS 直接引用学习资料

## 技术栈

- 前端（双端共享）：Vue 3 + TypeScript + Vite + Vue Router + Pinia，构建为 singlefile IIFE bundle
- 思源端：插件入口 TypeScript（CommonJS，`siyuan` 作为 external）
- 飞牛端：nitro（h3 2）统一网关 + `@trimjs/web-app` SDK（桌面文件选择），运行于 fnOS `nodejs_v22` 运行时
- 数据：JSON 持久化，存储实现按端适配（见「数据模型与存储布局」）

## 架构（monorepo）

```
npm workspaces（根 package.json 为 private 容器，版本号唯一来源）
├── packages/core      # 三端共享：全部功能（SPA + 业务 API + 桥接契约 + 可复用工具）
├── packages/siyuan    # 思源适配器：插件入口
└── packages/fnos      # 飞牛适配器：native .fpk（网关 + UI 桥接 + 打包）

                ┌────────────────────────────────────────┐
                │ packages/core（build:web → IIFE bundle）│
                │  App.vue / views / components / stores  │
                │  api/（业务封装）+ bridge/（宿主契约）    │
                │  crypto.ts / aiRetry.ts / aiPayload.ts  │ ← fnos 服务端也直接 import
                └───────────────┬────────────────────────┘
            ┌───────────────────┴────────────────────┐
   ┌────────▼─────────────┐                 ┌─────────▼──────────────┐
   │ packages/siyuan      │                 │ packages/fnos          │
   │ 插件入口（渲染进程内）  │                 │ .fpk 统一网关           │
   │ 顶栏图标 → 页签        │                 │ /app/ai-study/*        │
   │ 直接函数调用（无桥接）  │                 │ ├ ui/：iframe + shim   │
   │ loadData/saveData     │                 │ └ server/：nitro 路由   │
   └──────────────────────┘                 └────────────────────────┘
```

- **桥接契约**：`packages/core/src/bridge/` 定义 `StudyBridge`（能力 + 数据存取 + 资产 + NAS 选择等），core 只依赖契约；思源端在插件入口实现（同渲染进程直接函数调用），fnOS 端由 `ui/bridge-shim.js` 在页面内实现（`window.__AI_STUDY_BRIDGE__`，HTTP 调本应用网关）。
- **LLM 调用**：思源端经内核 `/api/network/forwardProxy` 代理（绕 CORS）；fnOS 端由网关服务端直连（无 CORS 问题），`ai-engine.ts` 复用 core 的 crypto/aiRetry/aiPayload。

## 数据模型与存储布局

数据以 JSON 持久化，模型见 `packages/core/src/types/appData.ts`，覆盖：

服务商、模型、任务模型绑定、调用日志、课程、章节、知识点、资料、资料-章节关联、题目、答题记录、错题、学习计划、学习任务、讲解记录、复习调度、学习记录。

**思源形态**磁盘布局（`data/storage/petal/siyuan-ai-study/`）：

```
data        全局：providers / models / taskModels / logs / courses 索引 / settings / cryptoKeyMaterial
course-<id> 每课程独立文件：chapters / knowledgePoints / materials / materialChapters /
            questions / examPapers / answerRecords / wrongQuestions / studyPlans /
            studyTasks / explainRecords / reviewSchedules / flashCards / studyLogs / conversationsDocs
```

拆分/合并纯函数在 `packages/siyuan/src/courseSplit.ts`（含单测 `packages/siyuan/src/__tests__/courseSplit.test.ts`）：
内存始终是完整 `AppData` 合并视图（前端无感知），保存时按 courseId 拆写、仅写有变化的文件；
间接实体归属规则：answerRecords/wrongQuestions 经 qId、studyTasks 经 planId、
reviewSchedules 经 kpId→qId→cardId、materialChapters 经 materialId；孤儿实体保留在全局文件。
旧布局（实体混在 `data`）在 onload 时一次性自动迁移（`hasCourseEntities` 判定，幂等）。

> 注：思源 `/api/query/sql` 为只读接口，无法建表/写数据，故数据存储采用 `loadData`/`saveData` 的 JSON 方案。

**fnOS 形态**磁盘布局（`{TRIM_PKGVAR}/data/`，持久运行数据目录，fnOS 按应用分配）：

```
<uid>.json   每个 fnOS 系统用户一个完整 AppData 单文件（原子写：tmp + rename）
```

按 uid 隔离由网关 `gateway-user.ts` 从请求上下文取得（统一网关注入），`user-data.ts` 负责读写；
NAS 资料以引用形式存路径（`source="nas"`、`assetPath=api/nas/file?path=...`），删除资料时跳过资产清理（不删用户原文件）。

## 开发

```bash
npm install           # 安装依赖（workspaces）
npm run build         # 构建（含 clean，会删 dist；日常迭代用下面两条不 clean，
                      #   否则思源内核会把插件当卸载：petal 掉线需重启思源）
npm run build:web     # core 前端 bundle（双端共用）
npm run build:plugin  # 思源插件主入口
npm run build:fnos    # 飞牛端（build:web + UI 打包 + nitro 服务端构建）
npm run pack:fnos     # 飞牛完整打包 → dist/fnos/ai-study.fpk
npm run make-link     # 软链接 dist 到思源插件目录（开发调试）
node scripts/make_dev_link.js /path/to/SiYuan   # 或手动指定工作空间
```

验证顺序：`npx vue-tsc --noEmit -p packages/siyuan/tsconfig.json && npx vue-tsc --noEmit -p packages/core/tsconfig.json` → `npx vitest run`（纯函数 + 组件测试，`packages/core/src/**/__tests__` 与 `packages/siyuan/src/__tests__`）→ 构建 → 思源重载插件 / fnOS 真机装 .fpk。

思源端：设置 → 集市 → 已下载 → 刷新 → 启用「AI 智能学习」，点击顶栏图标打开学习页签。
飞牛端：应用中心「本地安装」`dist/fnos/ai-study.fpk`，桌面打开「AI 智能学习」；
网关本地调试可用 `localDevPort`（3333，见 `packages/fnos/template.config.json`）。

## 功能清单

核心学习链路已全部打通：

- [x] 大模型服务商管理（OpenAI 兼容）、连通性测试、模型列表拉取、AI 任务模型分配
- [x] 资料上传与文档文本解析（PDF/Word/PPT/TXT/Markdown，含 GBK 回退与标题结构识别；扫描件 PDF 可选内核 OCR 提取正文）
- [x] 章节树（手动搭建 / 按标题自动识别，可选 AI 矫正去噪合并 / 批量导入与删除）、知识点 AI 抽取（分块、去重、章节绑定）
- [x] AI 出题（单选/多选/判断/简答/填空/翻译）、组卷刷题、即时批改、简答题 AI 阅卷
- [x] 错题归集（错误原因标记 / 毕业机制）、自研 SM2 间隔重复复习、闪卡
- [x] 费曼讲解评估（多轮）、AI 学习计划生成、学习统计与报告（导出 Markdown）
- [x] 知识图谱：AI 推理前置关系 / 手动连线、SVG 分层布局、掌握度着色、写入思源文档
- [x] 资料/章节/课程落库思源（可开关），课程/章节改名同步文档名，删除资料/课程级联清理（含资源目录源文件）
- [x] 飞牛 fnOS 端：native .fpk 统一网关、按 uid 数据隔离、AI 服务端直连、NAS 资料选择（桌面 pickUserFile → 后端 ACL 校验 → 流式读取 → 既有解析管线；删除不伤原文件，真机验证通过）

已知边界：

- 前端 UI 为中文单语（i18n 仅覆盖插件名/顶栏标题），英文界面待排期
- 删除资料时经 `removeUnusedAsset` 同步删除资源目录源文件；若源文件已被其他文档引用（如手动拖入笔记）或仍被其他资料共用，内核会跳过不删
- PDF 标题识别为字号/居中启发式，结构复杂的 PDF 需在目录预览中人工修正；可在「模型配置 → AI 任务模型分配」为「目录识别矫正」配置模型，重新识别时由 AI 自动去噪/合并/纠层（失败自动回退原始识别）
- 扫描件（纯图片 PDF）无文字层，需上传时勾选「OCR 识别扫描件」（逐页渲染图片调思源内核 OCR，耗时较长）；OCR 结果仅正文、无章节结构，目录需手动搭建；内核 OCR 仅思源桌面版可用，Web 版/移动端不可用
