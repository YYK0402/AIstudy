## 附：SiYuan 3.8.8 兼容修复（2026-10-22，实机排查结论）

**现象**：浏览器访问本地思源后顶栏无插件图标（看似"未启用"），内核日志 `dataChanges=[siyuan-ai-study]` 无限刷屏。

**根因**：`initData()` 每次插件加载**无条件回写** petal 数据文件；3.8.8 对未覆盖 `onDataChanged` 的插件，petal 数据变更会触发**整体 reload** → onload 再写 → 死循环；风暴中 `onLayoutReady`（注册顶栏图标）被状态机中断且无重试。

**修复**（`src/index.ts`）：
1. `initData` 仅在 `JSON.stringify(merged) !== JSON.stringify(loaded)` 时落盘（字段补齐/密钥迁移才写）；
2. 类中覆盖 `onDataChanged() {}` 空实现，opt-out 内核自动重载。

**配套注意**：
- 插件目录是符号链接 `~/SiYuan/data/plugins/siyuan-ai-study -> <repo>/dist`；`npm run build` 的 `clean` 会删 dist，导致内核把 petal 当卸载（需重启内核才恢复）。日常迭代用 `npm run build:web && npm run build:plugin`（不 clean）。
- 内核无插件重扫 API，petal 注册表只在启动/安装时更新；掉线时重启思源即可。
