# AI 智能学习（思源笔记插件）

基于思源笔记底座 + 可自定义大模型服务商的课程自学插件，融合**费曼输出式学习法**与**SM2 间隔重复**：

**资料导入 → 知识点拆解 → 学习计划 → 讲解学习 → 题库刷题 → 错题复盘 → 间隔复习 → 学习报告**，形成完整自学闭环。

- 适用版本：思源笔记 **3.8.0+**（桌面版体验完整；OCR 功能仅桌面版可用）
- 无需注册账号、无需第三方服务器：**自带大模型 API Key**（兼容任意 OpenAI 格式接口），全部学习数据保存在本机
- 插件入口在思源顶栏，点击后在**思源窗口内以自定义页签**打开整套学习界面；课程、知识点、资料、学习对话还可自动落库到你的笔记本

## 功能亮点

| 模块 | 功能 |
| --- | --- |
| 模型配置 | 任意 OpenAI 兼容服务商（MiniMax / DeepSeek / Kimi / 通义 / 自部署等），连通性测试、按任务分配模型、自定义提示词模板、失败重试与限速 |
| 课程管理 | 多课程并行、归档只读、课程级指定模型、结业模考、掌握度统计 |
| 资料导入 | PDF / Word / PPT / TXT / Markdown 文件、直接粘贴文本、绑定思源已有文档；扫描件 PDF 可选内核 OCR |
| 知识点 | AI 梳理资料结构、目录自动识别（可 AI 矫正）、AI 抽取知识点、标签筛选、四级掌握度 |
| 学习 | AI 生成每日学习计划；费曼讲解：AI 提问 → 你讲解 → AI 评分，多轮补强 |
| 刷题 | AI 出题（单选/多选/判断/简答/填空/翻译）、组卷（知识点/难度/题型/数量）、导入真题、即时批改、简答 AI 阅卷 |
| 复习 | 错题本（错误原因标记、毕业机制）、闪卡本、间隔重复到期浮现、定向复习 |

| 思源联动 | 课程 / 章节 / 资料 / 学习对话自动落库为笔记文档，在思源里照常检索阅读 |

## 安装

**插件仓库**：思源 → 设置 → 插件 → 插件仓库 → 搜索「AI 智能学习」→ 安装。

**手动安装**：下载插件 zip 包 → 思源 → 设置 → 插件 → 本地插件 → 导入 → 刷新启用，点击顶栏「AI 智能学习」图标打开页签。

## 快速上手

1. **配置大模型**：学习页签 → 「模型配置」→ ＋新增服务商（名称、API 地址、API Key）→ 点「测试」确认连通 → 添加模型 → 为各 AI 任务分配模型。
2. **创建课程**：「学习首页」→ ＋新建课程（名称 / 简介 / 学习目标 / 预计周期 / 目录构建模式）。
3. **导入资料**：进入课程 → 「课程内容」→ ＋上传资料（建议勾选「AI 梳理」）→ 资料解析完成后点「抽取知识点」。
4. **开始自学**：「学习计划」生成每日计划 → 「开始学习」讲解知识点 → 「刷题练习」检验掌握 → 「复习计划」间隔巩固。

## 功能详解

### 模型配置（首次使用必做）

- **服务商**：任意 OpenAI 兼容接口。填写名称、API 地址（如 `https://api.minimaxi.com/v1`）、API Key（本地加密存储）、超时时间；可「测试」连通性、从服务端拉取模型列表、启用/停用。
- **模型参数**：每个模型可设最大上下文、温度、最大输出 token。
- **任务分配**：插件内每个 AI 任务（抽取知识点、AI 出题、讲解评估、目录识别矫正等）可单独指定模型，未指定的走全局默认；课程也可单独指定模型。
- **提示词模板**：每个任务的系统/用户提示词均可自定义（`{{变量}}` 占位），不满意 AI 表现时先调这里。
- **稳定性**：可配置 AI 失败自动重试次数（0-2）与每分钟请求上限（超限自动排队）。
- **调用日志**：每次 AI 调用的 token 用量与状态可查。

### 课程管理

- 「学习首页」展示全部课程卡片（进行中/已归档）、今日任务汇总；点击卡片进入课程。
- 课程可归档（归档后内容只读：生成计划/出题/上传资料入口隐藏），可取消归档。
- 「课程主页」展示掌握度分布、待复习数、错题数、题目总数、今日任务，以及**结业模考**入口（全课程知识点组卷，需题库已有题目）。

### 课程内容：目录 / 知识点 / 资料

**目录结构**：章节 → 单元两级树。

- 建课时可选**手动模式**（先搭目录再绑资料）或**自动模式**（上传后按标题自动识别）。
- 「重新识别目录」聚合所有资料的标题结构重建目录；结构复杂的 PDF 可配置「目录识别矫正」模型，由 AI 自动去噪/合并/纠层（失败自动回退原始识别）。

**知识点**：AI 从资料中抽取，自动绑定所属章节/单元；支持搜索、标签、批量删除；掌握度四级（未学/了解/掌握/精通），随讲解与答题更新。

**资料库**：

- 上传 PDF / Word / PPT / TXT / Markdown，或直接粘贴文本，或绑定思源已有文档（不复制副本）。
- 扫描件（纯图片、文字层不足的 PDF）上传时自动逐页调思源内核 OCR 提取正文（耗时较长，仅桌面版可用；OCR 结果无章节结构，目录需手动搭或「AI 梳理」）。
- 每份资料可单独：预览全文、🤖 AI 梳理（去页眉页脚水印、修复断行缺字、识别目录）、抽取知识点、删除。
- 后台任务（AI 梳理/抽取）进度见页签右上角铃铛。

### 学习计划

「学习计划」页由 AI 基于全部知识点生成按天计划（目标日期、每日时长），每天的任务列表展示在「学习首页」「课程主页」「开始学习」三处，勾选完成即记录。可随时「重新生成」；暂停/恢复计划。

### 开始学习（费曼讲解）

选一个知识点 → AI 提出费曼式提问 → 你用自己的话讲解 → AI 评分（≥60 分为合格）并给出评估与补强建议；可多轮继续直到掌握。全部讲解过的知识点进入「过往学习会话」，随时回看对话过程。开启思源落库后，每章/节的讲解对话会同步写入课程下的「学习对话」文档。

### 刷题练习

三种方式获得题目：

1. **AI 出题**：勾选知识点 → 选题型（单选/多选/判断/简答/填空/翻译）、难度、数量 → 开始出题。
2. **组卷刷题**：按题型/难度/**知识点范围（章-节-知识点树勾选）**筛选题库 → 选题目数量与顺序（随机/顺序）→ 开始刷题。
3. **导入真题**：按约定格式粘贴 Markdown（见[导入格式](#真题导入格式)），解析后可编辑导入，可挂到试卷名下。

刷题即时批改：客观题秒判，简答题由 AI 阅卷给分。答错 → 归入错题本、题目进入间隔复习池（次日到期）、关联知识点掌握度降一级、自动追加薄弱练习任务；答对 → 累计错题连对次数、勾掉当天对应练习任务。课程主页的「结业模考」会预填全课程知识点组卷。

### 错题本

错题按课程归集，可标记错误原因（概念不清 / 记忆遗漏 / 粗心）；每次答对累计牢固次数，达到阈值后「毕业」移出在管列表。支持按题型筛选，可导出 Markdown。

### 闪卡本与复习计划

- **闪卡**：每个知识点一张（正面问题 / 背面答案要点），AI 批量生成或手动创建。
- **间隔重复**：答错的题目与闪卡复习驱动 SM2 调度（难度因子/间隔天数/阶段），到期项目自动浮现在「复习计划」；支持单知识点定向复习（回想 → 揭示 → 自评，评「牢固」自动勾掉对应复习任务）。

### 知识图谱

知识点前置关系图：AI 自动推理「先学什么后学什么」，也可手动连线；节点按掌握度着色，点击查看详情；可一键写入思源文档。

### 学习报告

知识点掌握分布、答题正确率、讲解均分、学习时长（近 30 天趋势）、掌握度热力图（章节 × 知识点）、章节掌握树、**薄弱点清单 TOP N**（未掌握 + 低分讲解 + 高频错题加权排序）；可生成 AI 综合点评与建议并导出 Markdown。

## 思源联动与数据

**落库为笔记文档**（在「模型配置」页底部开启「资料持久化到思源」并填写笔记本名称，默认「AI 研习」；关闭则仅存插件数据）：

```
<笔记本>/
└── <课程名>/                 # 课程文档
    ├── <章节名>/             # 章节子文档
    │   ├── <单元名>/         # 单元子文档
    │   │   └── 学习对话       # 该单元下知识点的讲解对话（锚点区自动维护）
    │   └── 学习对话           # 该章节下（未挂单元）知识点的讲解对话
    └── 资料库/
        └── <资料名>           # 资料全文
```

课程/章节改名同步文档名；删除资料/课程级联清理文档（源文件若被其他文档引用则保留）。

**数据文件**（本地 JSON，可随时备份）：

```
<思源数据目录>/storage/petal/siyuan-ai-study/
├── data        # 全局：服务商/模型/设置/调用日志/课程索引
└── course-<id> # 每课程一个文件：章节/知识点/资料/题目/计划/任务/错题/闪卡…
```

> 迁移/备份学习数据：直接复制整个 `siyuan-ai-study` 目录；新设备复制回来后重载插件即可。

## 真题导入格式

按约定格式粘贴 Markdown（每块一题，块间用 `---` 分隔），解析后可编辑导入；未匹配知识点的题目不阻断导入，导入后可批量绑定。

```markdown
# 2024 考研政治真题
1. 题干文字……
A. 选项 A
B. 选项 B
C. 选项 C
D. 选项 D
答案: A
解析: （可选）
---
2. 判断题干……
答案: 对
---
3. 简答题干……
答案: 参考要点……
```

导入时可新建试卷（名称 + 年份）归档题目；「试卷管理」中可按试卷筛选/导出。

## 常见问题

**Q：支持哪些大模型？**
任何 OpenAI 兼容接口（`/chat/completions`）：MiniMax、DeepSeek、Kimi、通义、智谱、OpenAI、自部署（vLLM/Ollama 等）均可。AI 请求经思源内核 `forwardProxy` 转发，无 CORS 问题。

**Q：数据存在哪里？会同步到云端吗？**
全部保存在本机思源数据目录的 JSON 文件（见上）。开启落库后，课程内容会以笔记文档形式存在于你的笔记本，随思源同步策略走。

**Q：某门课程不想学了怎么办？**
课程卡片 →「归档」：内容只读、不再出现在今日任务，资料与文档都保留；随时可取消归档。

**Q：AI 梳理/抽取进度在哪看？**
页签右上角铃铛（后台任务），完成后自动提示。

**Q：扫描版 PDF 能识别吗？**
能，文字层不足时上传即自动逐页 OCR（耗时较长；仅思源桌面版支持内核 OCR）。OCR 结果只有正文没有标题结构，目录需手动搭建或「AI 梳理」。

**Q：为什么 AI 出题/讲解效果不理想？**
① 换能力更强的模型；② 在「提示词模板」里调整该任务的提示词；③ 检查资料正文质量（断行/缺字会影响出题）。

**Q：换了电脑怎么迁移？**
复制 `storage/petal/siyuan-ai-study/` 整个目录到新机器同一位置（落库的笔记文档随笔记本迁移），重载插件即可。
